About

What is Full Auto Forza Edition?

FAFE automates five of the most time-consuming repetitive tasks in Forza Horizon 6 — AFK Races for skill points, unlocking Wheelspin rewards from mastery trees, batch-buying any purchasable car, auto-spinning Super or normal Wheelspins, and deleting used cars from your garage.

It reads the game window directly and sends input via window messages, so it keeps working even when the game is unfocused, covered, or in the background. No file modification, no code injection — it simply simulates a human player.

Getting Started

Three steps to start

1

Pick your game monitor

Select the monitor your game is on. Detection templates ship built in and auto-scale — Race, Buy and Auto Wheelspins need no capturing.

2

Position the game, press Start

Place Forza Horizon 6 on the required screen, then click "Start" or press F9. FAFE counts down 3 seconds — with background mode on, you don't switch back.

3

Let it run

FAFE runs fully automatically. A live log shows every action in real time. To stop at any time, press F9 or click "■ Stop".
